# PDFluent Homebrew tap

```bash
brew tap pdfluent/tap

# The command-line tool
brew install pdfluent

# The desktop editor
brew install --cask pdfluent-editor
```

- `pdfluent` builds the [`pdfluent-cli`](https://crates.io/crates/pdfluent-cli) crate from source and installs the `pdfluent` binary.
- `pdfluent-editor` installs the PDFluent desktop editor from https://pdfluent.com/download.
